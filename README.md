# Marvel-Films-Profit-Dashboard
This dashboard illustrates the total box office earnings in the U.S. and internationally for MCU films. This dashboard was created using Streamlit.

The dataset is from Kaggle and features MCU films from 2008 to 2019, from Iron Man to the Infinity Saga. https://www.kaggle.com/datasets/darrylljk/marvel-cinematic-universe-films-box-office?resource=download

The project uses the pandas library in Python as well as Streamlit to create the visualizations.
